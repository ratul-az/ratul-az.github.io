## Publish with GitHub Pages

1. Extract this ZIP.
2. Open the repository `ratul-az/ratul-az.github.io`.
3. Upload the contents of this folder to the repository root (not the enclosing folder).
4. Commit the changes to the publishing branch.
5. Open the GitHub Pages site and verify the page and repository links.
